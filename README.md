# 橘杏咲の立ち話もなんですから！（中日对照专栏合集）

收录《声優グランプリ》WEB 连载专栏《橘杏咲の立ち話もなんですから！》第 1–28 回（2024 年 8 月 – 2026 年 11 月）正文、配图与「橘さんに質問！」问答的中日对照静态博客站。

## 特性
- **独立静态多页面**：主页 `index.html` + 第 1–28 回独立页面 `episodes/ep01.html`–`ep28.html`，每页轻量秒开，支持单回直链分享。
- **双栏阅读体验**：左侧固定目录栏仅展示回数与年月，右侧专注单回正文与本地高清原图（点击可放大）。
- **语言显示切换**：支持「中日 / 仅中 / 仅日」三态切换，跨页自动记忆偏好。
- **全站关键词检索**：主页与侧边栏均可实时搜索全部 28 回的中日正文、导读、当月目标与问答，跨页自动高亮命中词。
- **零构建直接托管**：纯原生 HTML / CSS / JS + 本地图片，已附 `.nojekyll`，直接推送至 GitHub 仓库并开启 GitHub Pages 即可上线。
